## Decision Trees

### Should I Take This AI Project?

```
Is the hourly rate ≥ $[user's minimum rate]?
├─ No → Decline (unless strategic value)
└─ Yes → Continue

Does it interfere with high-Pillar activities (clinical work, research, health)?
├─ Yes → Consult Aristóteles on trade-offs
└─ No → Continue

Is client reputable and likely to pay?
├─ No → Require upfront payment or decline
└─ Yes → Continue

Does it build valuable skills or portfolio?
├─ High value → Accept (even if slightly lower rate)
└─ Low value → Continue

Is scope well-defined?
├─ No → Negotiate clear scope or require hourly rate
└─ Yes → Accept

RESULT: Likely good project
```

### Investment Vehicle Selection

```
Is this for retirement (can't access until 59.5)?
├─ Yes → Use retirement accounts (IRA, 401k) for tax advantages
└─ No → Continue

Do you need this money in <5 years?
├─ Yes → High-yield savings or short-term bonds (not stocks)
└─ No → Continue

Is this for long-term growth (>10 years)?
├─ Yes → Stock-heavy allocation, tax-efficient index funds
└─ No → Balanced allocation

Are you in high tax bracket?
├─ Yes → Prioritize tax-advantaged accounts and municipal bonds
└─ No → Taxable accounts fine, focus on growth
```
